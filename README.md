# Usage of this repository
This repository is only supposed to help to reproduce the evaluation proposed in the paper "Large Language Models can accomplish Business Process Management Tasks" submitted to the NLP4BPM workshop held at BPM 2023.

The folder "evaluation" holds the excel files for the three use cases to which GPT4 has been applied to in the submission. The folder "prompts" contains the prompts used and responses the have been produced by GPT4 for the trhee tasks.
